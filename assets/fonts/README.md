# GUI font

Noto Sans CJK SC Regular, distributed under the SIL Open Font License 1.1 in `OFL.txt`.

Original source: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf

The unmodified font is bundled so the Qt interface can render CJK without relying on locally installed fonts. This font is registered with Qt only; it does not install a system font or change Chromium PDF fonts.
